# API Practica

## Ejecutar el proyecto

Abre una terminal y entra al backend:

```bash
cd Backend
```

Genera la base de datos:

```bash
npm run merge
```

Inicia el servidor:

```bash
npm run server
```

La API quedará corriendo en:

```bash
http://localhost:3000
```

## Abrir el frontend

Abre el archivo `Frontend/index.html` con **Open with Live Server**.

## Orden correcto

```bash
cd Backend
npm run merge
npm run server
```

Después abre `Frontend/index.html` con **Open with Live Server**.
